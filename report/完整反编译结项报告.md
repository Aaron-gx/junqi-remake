## 三、SPAK 资源容器（核心突破）

### 3.1 格式

```
0x00  u32 "SPAK"           0x4B415053
0x04  u32 version          = 1
0x08  u32 index_off        索引区绝对偏移
0x0C  u32 index_csize      索引区（异或+压缩）长度
0x10  u32 checksum         crc32(索引密文) ^ 0x2713
0x14  u32 index_raw        索引区解压长度 = 28 × N
0x18～index_off             载荷区
index_off～EOF              索引区
```

索引条目 28 字节：`16B 目录键 | u32 绝对偏移 | u32 csize | u32 usize`，首尾相接。

### 3.2 算法（来自 Ghidra 反编译）

- 异或：`data[i] ^= KEY[i % 32]`，**每条资源相位从 0 开始**；`KEY` @ `0x001356d4`：
  `c2cbe5e7ce5c4ac411ca6c9906f476f86d4fcbb62621de0e6a67874c93f0d523`
- 解压：标准 zlib（`inflateInit2_`, windowBits 15）
- 分支：`csize != usize` → 异或后 inflate；`csize == usize` → 异或后原样存储

### 3.3 结果

| 组 | 条目 | 解出 | 备注 |
|---|---:|---:|---|
| data  | 122 | 122 | 配置/文本/音效/关卡（`data/lay/*.lay`、`data/ad/*.cfg`…）|
| datah | 255 | 255 | 图像 + 对话框布局 XML |
| datax | 313 | 313 | 高清/扩展皮肤图像 + 布局 |
| **合计** | **690** | **690** | **100%** |

产物类型：339 XML、196 PNG、119 BIN、18 WAV、10 JPG、6 TXT、2 CFG。

### 3.4 资源名恢复

- `data` 组目录键 = **MD5(路径)** → 恢复 **108/122** 个真名。
- `datah`/`datax` 组键**不可逆**：已系统排除路径 MD5（多前缀/后缀/编码/大小写/密度变体）、
  内容 MD5、数值 ID、组名前缀等假设；两组键集合与 `data` 零交集，属独立命名空间，
  资源名应由运行期拼装。这些条目以 `<md5>.<ext>` 命名（附类型/PNG 尺寸）。

> 教训：早期 6 项纯统计实验全部为**假阴性**，因未掌握调用约定（偏移基准、相位基准、分支条件）。
> 详见 `00-triage/spak-analysis.md`。
